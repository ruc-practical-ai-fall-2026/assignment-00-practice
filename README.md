# Assignment 00: Practice Assignment

This is a practice assignment for Practical AI. Hopefully, it will be the easiest assignment of the semester! Although, some setup will be required for it to work as intended so the intent of this assignment is to ensure that setup has been done successfully so we can focus entirely on the core aspects of subsequent assignments.

This assignment requires you to complete the following tasks:

1. Follow the [development environment setup](https://github.com/ruc-practical-ai-fall-2026/tutorials/blob/main/01-development-environment-setup.md) tutorial. We will walk though this together in class.
2. Follow the [assignments](https://github.com/ruc-practical-ai-fall-2026/tutorials/blob/main/05-assignments.md) tutorial. Follow the steps to make your own repository to take the assignment. Be sure to read and beware of the common errors (such as attempting to work in the instructor repositories).
3. Complete the Hello World program in this repository and submit it correctly, following the instructions in the previous step.
